# Mẫu tài liệu

> (đang viết) Chép mẫu vào dự án, điền chỗ `<...>`. Mỗi mẫu ghi rõ ai viết, khi nào, cổng nào dùng.

| File | Dùng cho |
|---|---|
| [`PROJECT.md`](PROJECT.md) | PROJECT.md — vấn đề, người dùng, MVP, chỉ số, phạm vi không làm |
| [`PLAN.md`](PLAN.md) | PLAN.md — kế hoạch task T-xxx có Gate máy kiểm (đầu vào autopilot) |
| [`PROGRESS.md`](PROGRESS.md) | PROGRESS.md — trạng thái để phiên sau tiếp tục |
| [`SPEC.md`](SPEC.md) | SPEC-<tính-năng>.md — đặc tả tính năng, Given/When/Then, ca biên |
| [`ADR.md`](ADR.md) | ADR-NNNN.md — bản ghi quyết định kiến trúc |
| [`THREAT-MODEL.md`](THREAT-MODEL.md) | THREAT-MODEL.md — tài sản, ranh giới, STRIDE, biện pháp |
| [`RUNBOOK.md`](RUNBOOK.md) | RUNBOOK.md — vận hành, lệnh, cảnh báo, liên hệ |
| [`POST-MORTEM.md`](POST-MORTEM.md) | POST-MORTEM.md — sự cố không đổ lỗi, hành động |
| [`DPIA.md`](DPIA.md) | DPIA.md — đánh giá tác động bảo vệ dữ liệu cá nhân |
| [`GO-NO-GO.md`](GO-NO-GO.md) | GO-NO-GO.md — báo cáo phát hành: BLOCKER/SHOULD/NICE, bằng chứng |
| [`RELEASE-NOTES.md`](RELEASE-NOTES.md) | RELEASE-NOTES.md — ghi chú phát hành cho người dùng |
| [`API-CONTRACT.md`](API-CONTRACT.md) | API-CONTRACT.md — hợp đồng API trước khi chia việc |
